# Implementation Slice Skill

Use this skill when implementing a scoped slice of work.

## Goals
- implement only the agreed slice
- make the smallest necessary change
- preserve maintainability
- leave clear handoff notes

## Rules
- do not silently expand scope
- do not introduce speculative abstractions
- match existing repository style
- touch only what is needed
- verify functionality before declaring completion

## Completion Checklist
Before finishing:
- confirm scope alignment
- confirm code fits repo conventions
- update or add tests where practical
- document assumptions
- document known limitations
- prepare reviewer and tester handoff notes

## Handoff Content
Always include:
- what was built
- what was intentionally not built
- files changed
- tests added or updated
- known risks
- reviewer focus areas
- tester focus areas
