# Feature Planning Skill

Use this skill when planning a new feature or significant change.

## Planning Goals
- understand the problem
- identify scope and non-scope
- surface assumptions
- identify open questions
- compare options
- recommend the smallest viable path
- break work into implementation-ready tasks

## Required Sections
A good plan should include:
- problem summary
- assumptions
- open questions
- scope proposal
- architecture options
- recommendation
- task breakdown
- risks and tradeoffs

## PB Lab Bias
For PB Lab work:
- prefer one clear vertical slice
- optimize for demoability
- avoid solving future phases prematurely
- separate MVP from follow-up work
